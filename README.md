# Telegram-бот підписки за USDT

Продає доступ до приватного Telegram-каналу за USDT у мережах BSC, ETH, TRON,
TON, SOL. Платежі розпізнаються за унікальною сумою інвойса, доступ видається
персональним посиланням-заявкою, підписка автоматично продовжується й
знімається після закінчення.

## Як це працює

1. Юзер обирає тариф і мережу — бот видає адресу й **унікальну суму**
   (29.06, 29.08, ...). Саме хвіст суми ідентифікує платіж.
2. Фоновий сканер кожні 40 с перевіряє гаманець і зараховує однозначні збіги.
   Юзер може й сам надіслати хеш — тоді інвойс відомий напевно.
3. Після зарахування бот видає інвайт-посилання з `creates_join_request`:
   заявку схвалює бот і лише тому, у кого є власна активна підписка. Переслане
   другові посилання не спрацює.
4. За 3 дні й за 1 день до кінця приходять нагадування, після закінчення —
   видалення з каналу.

Недоплату можна докинути: зараховані суми накопичуються по інвойсу, доплата
підтверджується хешем другої транзакції.

## Локальний запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заповнити BOT_TOKEN, OWNER_ID, CHANNEL_ID, ключі API
python run.py
```

За замовчуванням береться SQLite (`bot.db`) — для розробки цього достатньо.
Таблиці створюються самі при старті, міграцій у проєкті немає.

## Тести

```bash
pip install pytest pytest-asyncio
pytest tests/ --asyncio-mode=auto
```
